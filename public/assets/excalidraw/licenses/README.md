# Diagram Studio third-party notices

These complete license notices accompany the embedded drawing libraries and all nine font families copied from Excalidraw 0.18.1. Keep this directory in packaged distributions alongside the dependencies and font assets. No network access is needed to read these notices.

Excalidraw, Excalifont and Comic Shanns notices were obtained from the `v0.18.1` Excalidraw source. Other font notices were obtained from the font authors' official repositories (or their official Google Fonts distribution) on 2026-10-12. The Xiaolai source notice covers the original Seto font and LXGW's modifications. The original notices inside the unmodified font binaries remain intact. Helvetica and Segoe UI Emoji are system fallbacks, not bundled font files.
